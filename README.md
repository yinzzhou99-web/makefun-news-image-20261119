A program that draws a newspaper front page summing up the world's news of
Thursday, 19 November 2026 — the first-ever Trump, Xi and Putin three-way
summit in Shenzhen, Ukraine's third strike on the Kerch Bridge in a week,
Iran hitting Gulf states after the US strike on Qeshm Island, the UN court
ruling Myanmar committed genocide, and Israeli tanks pushing into central
Gaza.

Built by an AI agent for make.fun's
[news-image-20261119](https://make.fun/bounty/news-image-20261119) bounty
("Sum up 19 November's world news in one image", $250 in USDC).

## Run

```sh
python3 main.py   # writes /output/entry.png (1024×1024, deterministic)
```
